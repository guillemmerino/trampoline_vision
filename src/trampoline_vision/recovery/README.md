# Recovery

Estructura preparada per reconstruir trajectòries d'actors després d'acabar
el tracking d'un vídeo. Els mòduls contenen només documentació de responsabilitats.
No hi ha algoritmes, classes públiques, lectura de configuració ni connexió amb CLI.

Ordre previst: contractes → configuració → fragments → evidències → associació
global → validació de cadenes → cas d'ús i resultats. El resolutor és una peça
substituïble i els criteris s'ajustaran amb experiments.

Vegeu [disseny i pla de construcció](../../../docs/28-recovery-package-design.md).
