# Dades locals

Els vídeos, deteccions, pesos i resultats locals no es versionen. El material actual es manté al
projecte germà TFM i es referencia des de manifests. No es crea cap còpia ni enllaç automàtic.

`manifests/*.example.json` són casos de referència versionats; el manifest 1.0 és executable. Els manifests locals es poden
anomenar `*.local.json`; queden exclosos. Les rutes són relatives a la carpeta del manifest.
Vegeu [entrades i dades heretades](../docs/05-inputs-and-legacy-data.md).
