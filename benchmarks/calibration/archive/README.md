# Estudis tancats

Aquí es conserven les decisions i les evidències que les fonamenten.
No cal obrir ni carregar aquest directori per executar el pipeline de producció.

| Estudi | Estat i contingut |
| --- | --- |
| [detection-preparation-v1](detection-preparation-v1/README.md) | Estudis de llindars YOLO, redundància, contenció, ancoratges, silueta, tall de candidates i comparació de zones. Inclou un antecedent de tracking amb ByteTrack. |

Cada estudi ha de separar **què es va provar**, **què es va observar**,
**què es va decidir** i **què no queda validat**. Un resultat històric no
s’ha de modificar per fer-lo coincidir amb el codi o la configuració actuals.
